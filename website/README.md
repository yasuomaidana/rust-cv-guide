# website

The Docusaurus site for the Rust CV Guide. It is a private package and is never published.

- Hand-written pages live in `docs/intro/`.
- `docs/opencv/` and `docs/status.md` are generated by `cargo run -p cvg-tools -- generate`; do not edit them.

```bash
bun install     # needs the wasm32-unknown-unknown target and wasm-bindgen-cli (see live/README.md)
bun start       # http://localhost:3000/rust-cv-guide/
bun run build   # fails on broken links
```
