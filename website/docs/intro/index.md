A guide for developers who know [OpenCV](https://docs.opencv.org/5.1.0/) and want to do the same work in pure Rust.

For each OpenCV 5.1 module and tutorial, this site names the Rust crate that covers it, shows tested code, and says
plainly where no pure-Rust answer exists yet.

## What you will find

Every page below is an OpenCV tutorial redone in pure Rust, with code that is compiled and tested in this repository.
Tutorials without a page yet are not hidden: the [roadmap](roadmap.md) lists every OpenCV 5.1 tutorial and module with its
status (`covered`, `partial`, `gap`, `not-planned` or `unreviewed`), so you can see what exists and what could come next.
