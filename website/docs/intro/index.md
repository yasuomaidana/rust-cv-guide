A guide for developers who know [OpenCV](https://docs.opencv.org/5.1.0/) and want to do the same work in pure Rust.

For each OpenCV 5.1 module and tutorial, this site names the Rust crate that covers it, shows tested code, and says
plainly where no pure-Rust answer exists yet.

:::note Work in progress
The catalog of OpenCV modules and the status dashboard are being built (see the repository's tickets).
:::
