## Goal

Measure how much worse one picture is than another with the two metrics of the OpenCV tutorial, PSNR and SSIM. The tutorial
applies them frame by frame to two videos; this page measures a photograph against a blurred copy, which is the same
computation for one frame. Both solutions — pure Rust (`image` only) and `oximedia-cv` — compute both PSNR and SSIM, and
the live view reports each crate's numbers and timing side by side.

## Theory

**PSNR** (peak signal-to-noise ratio) is a log of the mean squared error: `10 · log10(255² / MSE)` decibels for 8-bit pictures.
Higher is better, 30 to 40 dB is usually fine, and identical pictures have infinite PSNR (capped at 100 here, as in the
tutorial). It only compares pixel by pixel, so it does not know that a blur and a one-pixel shift look different to a person.

**SSIM** (structural similarity) compares 11×11 Gaussian windows (`σ = 1.5`) of the two pictures by their mean, their
contrast and how they vary together, and averages the result, from 0 to 1 (1 means identical). It reacts to loss of structure, such as blur.

```rust
//! OpenCV tutorial `tutorial_video_input_psnr_ssim` (PSNR and SSIM) in pure Rust with only the `image` crate.
//! Run with `cargo run -p cvg-snippets --example psnr`.

use cvg_snippets::common::gray_sample;
use image::{GrayImage, imageops};

/// What "worse quality" looks like for the demo: the picture blurred with spread `sigma`.
pub fn degrade(input: &GrayImage, sigma: f32) -> GrayImage {
    imageops::blur(input, sigma)
}

/// Mean squared error between two grey images of the same size.
pub fn mse(a: &GrayImage, b: &GrayImage) -> f64 {
    let squares: f64 = a
        .as_raw()
        .iter()
        .zip(b.as_raw())
        .map(|(x, y)| f64::from(x.abs_diff(*y)).powi(2))
        .sum();
    squares / a.as_raw().len() as f64
}

/// Peak signal-to-noise ratio in dB for 8-bit pictures; identical pictures give 100, as OpenCV's tutorial caps it.
pub fn psnr(a: &GrayImage, b: &GrayImage) -> f64 {
    let error = mse(a, b);
    if error < 1e-10 {
        100.0
    } else {
        10.0 * (255.0_f64 * 255.0 / error).log10()
    }
}

/// Mean structural similarity (SSIM) over 11×11 Gaussian windows (`sigma = 1.5`) in pure Rust.
pub fn ssim(a: &GrayImage, b: &GrayImage) -> f64 {
    let (w, h) = (a.width() as usize, a.height() as usize);
    if w < 11 || h < 11 {
        return 1.0;
    }
    let kernel = gaussian_11();
    let (ax, bx) = (to_f64(a), to_f64(b));
    let (mu_a, mu_b) = (blur_11(&ax, w, h, &kernel), blur_11(&bx, w, h, &kernel));
    let aa: Vec<f64> = ax.iter().map(|v| v * v).collect();
    let bb: Vec<f64> = bx.iter().map(|v| v * v).collect();
    let ab: Vec<f64> = ax.iter().zip(&bx).map(|(x, y)| x * y).collect();
    let (ma2, mb2, mab) = (
        blur_11(&aa, w, h, &kernel),
        blur_11(&bb, w, h, &kernel),
        blur_11(&ab, w, h, &kernel),
    );
    let (c1, c2) = ((0.01 * 255.0_f64).powi(2), (0.03 * 255.0_f64).powi(2));
    let mut total = 0.0;
    let mut count = 0usize;
    for y in 5..(h - 5) {
        for x in 5..(w - 5) {
            let i = y * w + x;
            let (ma, mb) = (mu_a[i], mu_b[i]);
            let (sa2, sb2, sab) = (ma2[i] - ma * ma, mb2[i] - mb * mb, mab[i] - ma * mb);
            let num = (2.0 * ma * mb + c1) * (2.0 * sab + c2);
            let den = (ma * ma + mb * mb + c1) * (sa2 + sb2 + c2);
            total += num / den;
            count += 1;
        }
    }
    total / count as f64
}

fn to_f64(img: &GrayImage) -> Vec<f64> {
    img.as_raw().iter().map(|&p| f64::from(p)).collect()
}

fn gaussian_11() -> [f64; 11] {
    let mut k = [0.0; 11];
    let mut sum = 0.0;
    for (i, slot) in k.iter_mut().enumerate() {
        let d = i as f64 - 5.0;
        *slot = (-d * d / (2.0 * 1.5 * 1.5)).exp();
        sum += *slot;
    }
    for slot in &mut k {
        *slot /= sum;
    }
    k
}

fn blur_11(src: &[f64], w: usize, h: usize, k: &[f64; 11]) -> Vec<f64> {
    let mut tmp = vec![0.0; w * h];
    for y in 0..h {
        for x in 5..(w - 5) {
            tmp[y * w + x] = (0..11).map(|i| src[y * w + x + i - 5] * k[i]).sum();
        }
    }
    let mut out = vec![0.0; w * h];
    for y in 5..(h - 5) {
        for x in 5..(w - 5) {
            out[y * w + x] = (0..11).map(|i| tmp[(y + i - 5) * w + x] * k[i]).sum();
        }
    }
    out
}

/// Sigma the page starts with.
pub const SIGMA: f32 = 2.0;

/// The PSNR and SSIM of the building photo against a blurred copy.
pub fn report() -> String {
    let photo = gray_sample("building.jpg");
    let blurred = degrade(&photo, SIGMA);
    format!(
        "psnr = {:.2} dB\nssim = {:.4}",
        psnr(&photo, &blurred),
        ssim(&photo, &blurred)
    )
}

pub fn main() {
    println!("{}", report());
}
```

```rust
//! OpenCV tutorial `tutorial_video_input_psnr_ssim` with `oximedia-cv`'s quality metrics: PSNR and SSIM.
//! Run with `cargo run -p cvg-snippets --example oxi_quality`.

use cvg_snippets::{common::gray_sample, oxi};
use image::{GrayImage, imageops};
use oximedia_cv::quality::{psnr::calculate_buffer_psnr, ssim::calculate_ssim};

/// PSNR in dB between two 8-bit grey pictures of the same size.
pub fn psnr(a: &GrayImage, b: &GrayImage) -> f64 {
    calculate_buffer_psnr(a.as_raw(), b.as_raw(), 8).expect("pictures of the same size")
}

/// Structural similarity of the brightness, from 0 to 1; it looks at local structure, which PSNR does not.
pub fn ssim(a: &GrayImage, b: &GrayImage) -> f64 {
    let result =
        calculate_ssim(&oxi::frame_of(a), &oxi::frame_of(b)).expect("frames of the same size");
    result.per_plane[0]
}

/// Sigma the page starts with.
pub const SIGMA: f32 = 2.0;

/// PSNR and SSIM of the building photo against a blurred copy.
pub fn report() -> String {
    let photo = gray_sample("building.jpg");
    let blurred = imageops::blur(&photo, SIGMA);
    format!(
        "psnr = {:.2} dB\nssim = {:.4}",
        psnr(&photo, &blurred),
        ssim(&photo, &blurred)
    )
}

pub fn main() {
    println!("{}", report());
}
```

## Explanation

1. `degrade` blurs the photo with `imageops::blur`, a stand-in for "the same picture after lossy processing".
2. Pure Rust computes `psnr` and a separable 11×11 Gaussian-window `ssim` directly on `GrayImage` bytes.
3. `oximedia-cv` computes `calculate_buffer_psnr(a, b, 8)` and `calculate_ssim(&oxi::frame_of(a), &oxi::frame_of(b))` (luma plane).
4. Tests verify that both crates agree to within 0.01 dB on PSNR and 0.005 on SSIM across blur levels, and that identical pictures give SSIM 1.0 while structural distortion drops SSIM.

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `cv::PSNR(a, b)` (`getPSNR` in the tutorial) | `psnr` above (`image`), or `oximedia_cv::quality::psnr::calculate_buffer_psnr` |
| the tutorial's `getMSSIM(a, b)` | `ssim` above (`image`), or `oximedia_cv::quality::ssim::calculate_ssim` (luma plane) |
| `cv::GaussianBlur` (to degrade) | `image::imageops::blur` |

## Performance comparison

| Operation | Input | OpenCV | Pure Rust | oximedia / oxipix | oxi / Rust |
|---|---|---|---|---|---|
| PSNR | 640x480 grey | 0.256 ms | 0.396 ms | 0.400 ms | 1.01x |
| SSIM (11x11 Gaussian) | 640x480 grey | 6.360 ms | 7.128 ms | 105.017 ms | 14.73x |

:::warning Performance difference

- **SSIM (11x11 Gaussian):** oximedia-cv's SSIM (14.7x slower than pure Rust separable SSIM, 16.5x slower than OpenCV) runs a non-separable 2D 11x11 window loop with per-tap bounds checks per pixel instead of 5 separable 1D passes (cool-japan/oximedia#31).

:::
