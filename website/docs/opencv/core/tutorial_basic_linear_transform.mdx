## Goal

Adjust the contrast and brightness of an image using a point-wise linear transformation, matching OpenCV's
`convertTo` and basic linear transform tutorial.

## Theory

A linear transform modifies each pixel independently with a gain factor `α` and a bias offset `β`:

`dst(x, y) = α · src(x, y) + β`

- `α > 0` controls **contrast** by scaling the intensity spread. Values greater than 1 increase contrast, while values between 0 and 1 decrease it.
- `β` controls **brightness** by shifting all intensities up or down by a constant offset.
- Floating-point arithmetic can produce values outside the valid 8-bit range `0..=255`. OpenCV uses `cv::saturate_cast<uchar>` to clamp values into `0..=255`, preventing modular overflow.

## Code

Pure Rust uses `image::RgbImage::from_fn` to iterate over every coordinate and evaluate the transformation per channel.

:::note oximedia / oxipix status
Neither `oximedia-cv` 0.2.1 nor `oxipix` 0.1.0 currently provides a point-wise `α · p + β` contrast/brightness operator (`OXI-85` covers receipt CLAHE/unsharp enhancement only). An **oxipix** feature ticket (`OXI-88`) has been opened to expose `linear_transform(img, alpha, beta)` with CPU + optional `wgpu` acceleration.
:::

```rust
//! OpenCV tutorial `tutorial_basic_linear_transform` in pure Rust.
//! Run with `cargo run -p cvg-snippets --example basic_linear_transform`.

use cvg_snippets::common::{Figure, describe, sample};
use image::{DynamicImage, Rgb, RgbImage};

/// Adjusts contrast (`alpha`) and brightness (`beta`) for every pixel channel:
/// `dst(x, y) = clamp(alpha * src(x, y) + beta, 0, 255)`.
pub fn linear_transform(image: &RgbImage, alpha: f32, beta: f32) -> RgbImage {
    RgbImage::from_fn(image.width(), image.height(), |x, y| {
        let p = image.get_pixel(x, y);
        let f = |c: u8| (alpha * f32::from(c) + beta).clamp(0.0, 255.0).round() as u8;
        Rgb([f(p[0]), f(p[1]), f(p[2])])
    })
}

/// A photograph and the same photograph with contrast 1.3 and brightness +40.
pub fn figures() -> Vec<Figure> {
    let original = sample("coffee.png");
    let adjusted = linear_transform(&original, 1.3, 40.0);
    vec![
        ("original", DynamicImage::ImageRgb8(original)),
        ("adjusted", DynamicImage::ImageRgb8(adjusted)),
    ]
}

/// Describes one pixel of each figure.
pub fn report() -> String {
    describe(&figures(), 300, 150)
}

pub fn main() {
    println!("{}", report());
}
```

```rust
//! OpenCV tutorial `tutorial_basic_linear_transform` with the `opencv` crate (calls native OpenCV).
//! Run with `cargo run --example basic_linear_transform` inside `snippets-opencv`.

use cvg_opencv::{mat_rgb, rgb_mat};
use image::RgbImage;
use opencv::core::Mat;
use opencv::prelude::*;

/// `alpha * pixel + beta`, saturated: contrast and brightness (`Mat::convertTo`).
pub fn linear_transform(image: &RgbImage, alpha: f32, beta: f32) -> RgbImage {
    let (src, mut dst) = (rgb_mat(image).expect("mat"), Mat::default());
    src.convert_to(&mut dst, -1, f64::from(alpha), f64::from(beta))
        .expect("convertTo");
    mat_rgb(&dst).expect("image")
}

pub fn main() {
    let photo = cvg_snippets::common::sample("coffee.png");
    println!(
        "brightest channel: {:?}",
        linear_transform(&photo, 1.3, 40.0).iter().max()
    );
}
```

## Explanation

1. `sample("coffee.png")` loads a CC0 photograph (see `snippets/assets/ATTRIBUTION.md`).
2. `linear_transform` visits every pixel and builds a new `RgbImage` of the same size.
3. For each channel, `(alpha * f32::from(c) + beta).clamp(0.0, 255.0).round() as u8` scales, offsets, saturates to the valid interval and rounds, like `cv::saturate_cast<uchar>`.
4. `figures()` returns the original and the adjusted picture, which `main` saves for this page.

The `image` crate also has `imageops::brighten` (adds an integer offset, like `β`) and `imageops::contrast` (scales around
mid-grey by `((100 + c) / 100)²`, which is a different curve from `α`). Use the loop above when you need OpenCV's exact
`α · p + β`.

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `image.convertTo(dst, -1, α, β)` | `linear_transform(&image, α, β)` using `image::RgbImage::from_fn` (`oxipix` tracked in `OXI-88`) |
| `cv::saturate_cast<uchar>(α * p + β)` | `(alpha * f32::from(c) + beta).clamp(0.0, 255.0).round() as u8` |
| `cv::imread` / `cv::imwrite` | `image::open` / `RgbImage::save` |
| `cv::Mat` of 8-bit BGR | `image::RgbImage` (RGB order, not BGR) |
