## Goal

Find keypoints in a photograph: places that can be found again in another picture of the same scene. Both `imageproc`
and `oximedia-cv` implement **FAST-9** corners and **ORB-style** keypoints + binary descriptors, so the page lets you
choose the **same algorithm** on both crates and tune their inputs either together or independently.

## Theory

A good keypoint is distinctive and repeatable. **FAST-9** looks at 16 pixels on a circle around each pixel and calls it
a corner when 9 consecutive ring pixels are all brighter or all darker than the centre by a threshold; it is very fast and
gives many corners. **ORB-style** detectors add orientation and a 256-bit binary **BRIEF** descriptor so two views can be
matched by Hamming distance.

## Code

Both crates expose the matching algorithm pair:

- **FAST-9**: `imageproc::corners::corners_fast9` beside `oximedia_cv::detect::corner::FastDetector` (with non-maximum suppression).
- **ORB-style**: `imageproc::corners::oriented_fast` + `binary_descriptors::brief` beside `oximedia_cv::feature_extract::OrbExtractor` + `match_descriptors`.

```rust
//! OpenCV tutorial `tutorial_feature_detection` in pure Rust (`imageproc`):
//! supports both FAST-9 corners and ORB-style oriented FAST + BRIEF descriptors.
//! Run with `cargo run -p cvg-snippets --example fast`.

use cvg_snippets::common::{FeatureAlgorithm, gray_sample};
use image::{GrayImage, imageops};
use imageproc::binary_descriptors::brief::{TestPair, brief};
use imageproc::binary_descriptors::match_binary_descriptors;
use imageproc::corners::{corners_fast9, oriented_fast};
use imageproc::point::Point;
use std::collections::BTreeMap;

pub type Algorithm = FeatureAlgorithm;

/// The `max` strongest FAST-9 corners whose ring differs from the centre by more than `threshold` levels.
pub fn keypoints(input: &GrayImage, threshold: u8, max: usize) -> Vec<(f32, f32)> {
    let mut corners = corners_fast9(input, threshold);
    corners.sort_by(|a, b| b.score.total_cmp(&a.score));
    corners.truncate(max);
    corners.iter().map(|c| (c.x as f32, c.y as f32)).collect()
}

/// Deterministic 256-pair BRIEF sampling pattern inside the 31×31 patch.
fn brief_pairs() -> Vec<TestPair> {
    let mut state: u64 = 0x517c_c1b7_2722_0a95;
    let mut next = || -> u32 {
        state = state
            .wrapping_mul(6_364_136_223_846_793_005)
            .wrapping_add(1);
        ((state >> 32) as u32) % 31
    };
    (0..256)
        .map(|_| TestPair {
            p0: Point::new(next(), next()),
            p1: Point::new(next(), next()),
        })
        .collect()
}

/// ORB-style oriented FAST-9 keypoints (`edge_radius = 18`, keeping >= 17 px margin for BRIEF's 31×31 patch).
pub fn orb_keypoints(input: &GrayImage, threshold: u8, max: usize) -> Vec<(f32, f32)> {
    if input.width() <= 36 || input.height() <= 36 {
        return Vec::new();
    }
    oriented_fast(input, Some(threshold), max, 18, Some(1))
        .into_iter()
        .map(|c| (c.corner.x as f32, c.corner.y as f32))
        .collect()
}

/// Dispatches either FAST-9 or ORB-style keypoint detection with the shared `(threshold, max)` controls.
pub fn detect(input: &GrayImage, algo: Algorithm, threshold: u8, max: usize) -> Vec<(f32, f32)> {
    algo.run(input, threshold, max, keypoints, orb_keypoints)
}

/// Extracts ORB-style keypoints and 256-bit BRIEF descriptors using a fixed sampling pattern.
pub fn orb_extract(
    input: &GrayImage,
    threshold: u8,
    max: usize,
    pairs: &[TestPair],
) -> Vec<imageproc::binary_descriptors::brief::BriefDescriptor> {
    if input.width() <= 36 || input.height() <= 36 {
        return Vec::new();
    }
    let pts: Vec<Point<u32>> = oriented_fast(input, Some(threshold), max, 18, Some(1))
        .into_iter()
        .map(|c| Point::new(c.corner.x, c.corner.y))
        .collect();
    let pairs_vec = pairs.to_vec();
    brief(input, &pts, 256, Some(&pairs_vec))
        .map(|(descs, _)| descs)
        .unwrap_or_default()
}

/// Matches ORB-style BRIEF descriptors against a shifted crop and returns the most-voted `(dx, dy)` shift.
pub fn orb_recovered_shift(
    input: &GrayImage,
    dx: u32,
    dy: u32,
    max: usize,
) -> Option<((i32, i32), usize)> {
    let moved =
        imageops::crop_imm(input, dx, dy, input.width() - dx, input.height() - dy).to_image();
    let pairs = brief_pairs();
    let first = orb_extract(input, THRESHOLD, max, &pairs);
    let second = orb_extract(&moved, THRESHOLD, max, &pairs);
    let mut votes: BTreeMap<(i32, i32), usize> = BTreeMap::new();
    for (a, b) in match_binary_descriptors(&first, &second, 32, Some(7)) {
        let shift = (
            a.corner.x as i32 - b.corner.x as i32,
            a.corner.y as i32 - b.corner.y as i32,
        );
        *votes.entry(shift).or_default() += 1;
    }
    votes.into_iter().max_by_key(|(_, count)| *count)
}

/// Settings the page starts with.
pub const THRESHOLD: u8 = 20;
pub const MAX: usize = 300;

/// Counts FAST-9 corners and ORB-style keypoints on the building photo.
pub fn report() -> String {
    let photo = gray_sample("building.jpg");
    let all = keypoints(&photo, THRESHOLD, usize::MAX).len();
    let kept = keypoints(&photo, THRESHOLD, MAX).len();
    let orb_kept = orb_keypoints(&photo, THRESHOLD, MAX).len();
    format!("corners = {all}\nkept = {kept}\norb_kept = {orb_kept}")
}

pub fn main() {
    println!("{}", report());
}
```

```rust
//! OpenCV tutorial `tutorial_feature_detection` and `tutorial_feature_description` with `oximedia-cv`:
//! supports both FAST-9 (`FastDetector`) and ORB-style (`OrbExtractor`) beside `imageproc`.
//! Run with `cargo run -p cvg-snippets --example oxi_orb`.

use cvg_snippets::common::{FeatureAlgorithm, gray_sample};
use image::{GrayImage, imageops};
use oximedia_cv::detect::corner::{CornerDetector, FastDetector};
use oximedia_cv::feature_extract::{OrbExtractor, match_descriptors};
use std::collections::BTreeMap;

pub type Algorithm = FeatureAlgorithm;

/// Grey levels as the 0 to 1 floats `OrbExtractor` takes.
fn unit(image: &GrayImage) -> Vec<f32> {
    image
        .as_raw()
        .iter()
        .map(|p| f32::from(*p) / 255.0)
        .collect()
}

/// FAST-9 corners via `oximedia_cv::detect::corner::FastDetector`, keeping the `max` strongest.
pub fn fast_keypoints(input: &GrayImage, threshold: u8, max: usize) -> Vec<(f32, f32)> {
    let detector = FastDetector::new().with_threshold(threshold).with_nms(true);
    let mut corners = detector
        .detect(input.as_raw(), input.width(), input.height())
        .unwrap_or_default();
    corners.sort_by(|a, b| b.response.total_cmp(&a.response));
    corners.truncate(max);
    corners
        .into_iter()
        .map(|c| (c.x as f32, c.y as f32))
        .collect()
}

/// ORB-style keypoints and their binary descriptors; `threshold` is on the 0 to 255 scale.
fn extract(
    input: &GrayImage,
    threshold: u8,
    max: usize,
) -> (
    Vec<(f32, f32)>,
    Vec<oximedia_cv::feature_extract::BriefDescriptor>,
) {
    let extractor = OrbExtractor {
        max_features: max,
        fast_threshold: f32::from(threshold) / 255.0,
    };
    let (points, descriptors) = extractor.extract(
        &unit(input),
        input.width() as usize,
        input.height() as usize,
    );
    (points.iter().map(|k| (k.x, k.y)).collect(), descriptors)
}

/// The `max` strongest ORB-style keypoints.
pub fn keypoints(input: &GrayImage, threshold: u8, max: usize) -> Vec<(f32, f32)> {
    extract(input, threshold, max).0
}

/// Dispatches either FAST-9 or ORB-style keypoint detection with the shared `(threshold, max)` controls.
pub fn detect(input: &GrayImage, algo: Algorithm, threshold: u8, max: usize) -> Vec<(f32, f32)> {
    algo.run(input, threshold, max, fast_keypoints, keypoints)
}

/// Matches the picture against a copy cropped by `(dx, dy)` and returns the shift most matches agree on, with how many do.
pub fn recovered_shift(
    input: &GrayImage,
    dx: u32,
    dy: u32,
    max: usize,
) -> Option<((i32, i32), usize)> {
    let moved =
        imageops::crop_imm(input, dx, dy, input.width() - dx, input.height() - dy).to_image();
    let (first, first_descriptors) = extract(input, THRESHOLD, max);
    let (second, second_descriptors) = extract(&moved, THRESHOLD, max);
    let mut votes: BTreeMap<(i32, i32), usize> = BTreeMap::new();
    for (i, j, _) in match_descriptors(&first_descriptors, &second_descriptors, 20) {
        let shift = (
            (first[i].0 - second[j].0).round() as i32,
            (first[i].1 - second[j].1).round() as i32,
        );
        *votes.entry(shift).or_default() += 1;
    }
    votes.into_iter().max_by_key(|(_, count)| *count)
}

/// Settings the page starts with.
pub const THRESHOLD: u8 = 20;
pub const MAX: usize = 300;

/// Reports FAST-9 and ORB-style counts on the building photo plus the matched shift.
pub fn report() -> String {
    let photo = gray_sample("building.jpg");
    let fast_found = fast_keypoints(&photo, THRESHOLD, MAX).len();
    let orb_found = keypoints(&photo, THRESHOLD, MAX).len();
    let shift = recovered_shift(&photo, 12, 7, MAX);
    format!("fast = {fast_found}\nkeypoints = {orb_found}\nshift = {shift:?}")
}

pub fn main() {
    println!("{}", report());
}
```

## Explanation

1. Selecting **FAST-9** runs `corners_fast9` (`imageproc`) beside `FastDetector::new().with_threshold(..).with_nms(true)` (`oximedia-cv`), keeping the `max` strongest corners.
2. Selecting **ORB (keypoints + descriptors)** runs `oriented_fast` (`imageproc`) beside `OrbExtractor` (`oximedia-cv`). Note that `OrbExtractor` finds scale-space blobs internally, while `oriented_fast` scores FAST-9 corners with intensity-centroid orientation.
3. Both examples also match 256-bit binary descriptors against a shifted crop `(12, 7)` and recover the exact translation shift by majority vote.
4. Use the **Sync parameters** checkbox in the live demo below to compare both crates on identical inputs, or uncheck it to pick a different algorithm, threshold, or keypoint cap per crate.

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `cv::FAST(img, keypoints, threshold)` | `imageproc::corners::corners_fast9` or `oximedia_cv::detect::corner::FastDetector` |
| `cv::ORB::create(n)->detectAndCompute(..)` | `imageproc::corners::oriented_fast` + `brief`, or `oximedia_cv::feature_extract::OrbExtractor::extract` |
| `cv::BFMatcher(NORM_HAMMING).match(..)` | `imageproc::binary_descriptors::match_binary_descriptors` or `oximedia_cv::feature_extract::match_descriptors` |
| `cv::drawKeypoints` | `common::draw_points`, a few lines |
