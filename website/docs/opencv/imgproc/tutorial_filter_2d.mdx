## Goal

Apply a kernel of your own to a photograph, as OpenCV's `filter2D` does, and see what different kernels do: the normalised box
filter of the tutorial, and sharpen, outline and emboss kernels. Both `imageproc` and `oximedia-cv` are shown side by side.

## Theory

A kernel is a small grid of weights. For each pixel the output is the weighted sum of the neighbourhood under the kernel
(strictly, correlation; OpenCV's `filter2D`, `imageproc` and `oximedia-cv` do not flip the kernel). A normalised box has equal weights
that add to 1, so it averages and blurs. A sharpen kernel has weights adding to 1 as well, but a strong centre and negative
neighbours, so it adds the difference from the neighbours back. An outline kernel has weights adding to 0, so flat areas give
0 and only changes remain. Results outside 0 to 255 are clamped.

```rust
//! OpenCV tutorial `tutorial_filter_2d` in pure Rust: convolution with a kernel of your own.
//! Run with `cargo run -p cvg-snippets --example filter2d`.

use cvg_snippets::common::{Figure, describe, rgb_figures, sample};
use image::RgbImage;
use imageproc::{filter::filter_clamped, kernel::Kernel};

/// The kernels of the page, in the order its menu lists them.
#[derive(Clone, Copy, Debug)]
pub enum Preset {
    /// Every weight equal: the normalised box filter.
    Box(u32),
    /// Adds the difference from the four neighbours back to the centre.
    Sharpen,
    /// Bright where the centre differs from all eight neighbours.
    Outline,
    /// Shades by the slope along the diagonal.
    Emboss,
}

impl Preset {
    /// The weights, row by row, and the side of the square kernel.
    fn weights(self) -> (Vec<f32>, u32) {
        match self {
            Preset::Box(side) => (
                vec![1.0 / (side * side) as f32; (side * side) as usize],
                side,
            ),
            Preset::Sharpen => (vec![0., -1., 0., -1., 5., -1., 0., -1., 0.], 3),
            Preset::Outline => (vec![-1., -1., -1., -1., 8., -1., -1., -1., -1.], 3),
            Preset::Emboss => (vec![-2., -1., 0., -1., 1., 1., 0., 1., 2.], 3),
        }
    }
}

/// `cv::filter2D`: slides the kernel over every channel and clamps the result to 0 to 255.
pub fn filter_2d(input: &RgbImage, preset: Preset) -> RgbImage {
    let (weights, side) = preset.weights();
    filter_clamped(input, Kernel::new(&weights, side, side))
}

/// The photo and four kernels applied to it.
pub fn figures() -> Vec<Figure> {
    let input = sample("chelsea.png");
    let results = [
        ("box", filter_2d(&input, Preset::Box(5))),
        ("sharpen", filter_2d(&input, Preset::Sharpen)),
        ("outline", filter_2d(&input, Preset::Outline)),
        ("emboss", filter_2d(&input, Preset::Emboss)),
    ];
    rgb_figures(input.clone(), results)
}

/// Describes one pixel of each figure.
pub fn report() -> String {
    describe(&figures(), 225, 150)
}

pub fn main() {
    println!("{}", report());
}
```

```rust
//! OpenCV tutorial `tutorial_filter_2d` using `oximedia-cv::image::filter::ConvolutionKernel`.
//! Run with `cargo run -p cvg-snippets --example oxi_filter2d`.

use cvg_snippets::{
    common::{Figure, chelsea_variants, describe},
    oxi,
};
use image::RgbImage;
use oximedia_cv::image::filter::ConvolutionKernel;

/// Builds the convolution kernel for `kind` (`0` = box of `side × side`, `1` = sharpen, `2` = outline, `3` = emboss).
pub fn kernel_for(kind: u32, side: u32) -> ConvolutionKernel {
    match kind {
        0 => {
            let s = (side | 1) as usize;
            ConvolutionKernel::new(vec![1.0 / (s * s) as f64; s * s], s, s)
        }
        1 => ConvolutionKernel::sharpen(),
        2 => ConvolutionKernel::new(vec![-1., -1., -1., -1., 8., -1., -1., -1., -1.], 3, 3),
        _ => ConvolutionKernel::emboss(),
    }
}

/// `cv::filter2D` via `oximedia-cv`'s `ConvolutionKernel` applied per colour channel.
pub fn filter_2d(input: &RgbImage, kind: u32, side: u32) -> RgbImage {
    let kernel = kernel_for(kind, side);
    oxi::per_channel(input, |plane| {
        oxi::run(plane, |bytes, w, h| kernel.apply(bytes, w, h))
    })
}

const KERNELS: [(&str, (u32, u32)); 4] = [
    ("box", (0, 5)),
    ("sharpen", (1, 3)),
    ("outline", (2, 3)),
    ("emboss", (3, 3)),
];

/// The photo and four kernels applied to it.
pub fn figures() -> Vec<Figure> {
    chelsea_variants(KERNELS, |img, (k, s)| filter_2d(img, k, s))
}

/// Describes one pixel of each figure.
pub fn report() -> String {
    describe(&figures(), 225, 150)
}

pub fn main() {
    println!("{}", report());
}
```

## Explanation

1. `Preset::weights` (`imageproc`) and `kernel_for` (`oximedia-cv`) build the same row-major kernels: `1 / side²` box, sharpen, outline, and emboss.
2. `imageproc::filter::filter_clamped` slides an `f32` kernel over RGB directly, while `oximedia_cv::image::filter::ConvolutionKernel` operates on grey bytes in `f64`, so the `oximedia-cv` example runs each colour plane through `oxi::per_channel`.
3. A kernel with weights adding to 1 keeps the brightness; adding to 0 gives black on flat areas. Tests verify parity between the two crates within ~1 grey level.

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `cv::filter2D(src, dst, -1, kernel)` | `imageproc::filter::filter_clamped` or `oximedia_cv::image::filter::ConvolutionKernel::apply` |
| `Mat::ones(k, k, CV_32F) / (k * k)` | `vec![1.0 / (k * k) as f32; k * k]` |
| `cv::blur(src, dst, Size(k, k))` | the same box kernel |
