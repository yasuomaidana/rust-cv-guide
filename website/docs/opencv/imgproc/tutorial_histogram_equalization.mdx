## Goal

Stretch the grey levels of a flat-looking photograph across the whole 0..=255 range with histogram equalisation, as
`cv::equalizeHist` does. Both `imageproc` and `oximedia-cv` implement it side by side.

## Theory

Count how many pixels have each grey level (the histogram) and accumulate the counts into a cumulative distribution
`cdf(v)`. Mapping every level `v` to `255 · cdf(v)` makes the output levels roughly equally frequent, which spreads out
crowded levels and raises the contrast of hazy images.

```rust
//! OpenCV tutorial `tutorial_histogram_equalization` in pure Rust.
//! Run with `cargo run -p cvg-snippets --example equalize`.

use cvg_snippets::common::{Figure, describe, luma_pair_figures};
use image::GrayImage;
use imageproc::contrast::equalize_histogram;

/// `cv::equalizeHist`: spread the grey levels over the whole 0..=255 range.
pub fn equalize(input: &GrayImage) -> GrayImage {
    equalize_histogram(input)
}

/// A hazy photo in grey levels and the same photo with its histogram equalised.
pub fn figures() -> Vec<Figure> {
    luma_pair_figures("building.jpg", "equalized", equalize)
}

/// Describes one pixel of each figure.
pub fn report() -> String {
    describe(&figures(), 100, 60)
}

pub fn main() {
    println!("{}", report());
}

//! OpenCV tutorial `tutorial_histogram_equalization` using `oximedia-cv::image::histogram_ext::equalize_histogram`.
//! Run with `cargo run -p cvg-snippets --example oxi_equalize`.

use cvg_snippets::common::{Figure, describe, luma_pair_figures};
use image::GrayImage;
use oximedia_cv::image::histogram_ext::equalize_histogram;

/// `cv::equalizeHist` via `oximedia-cv`.
pub fn equalize(input: &GrayImage) -> GrayImage {
    let (w, h) = input.dimensions();
    let bytes = equalize_histogram(input.as_raw());
    GrayImage::from_raw(w, h, bytes).expect("same dimensions")
}

/// A hazy photo in grey levels and the same photo with its histogram equalised.
pub fn figures() -> Vec<Figure> {
    luma_pair_figures("building.jpg", "equalized", equalize)
}

/// Describes one pixel of each figure.
pub fn report() -> String {
    describe(&figures(), 100, 60)
}

pub fn main() {
    println!("{}", report());
}
```

## Explanation

1. The building photo is converted to grey, because equalisation works on a single channel. (For colour, equalise the luminance and keep the chroma.)
2. Both `imageproc::contrast::equalize_histogram` and `oximedia_cv::image::histogram_ext::equalize_histogram` build the histogram, compute the cumulative distribution and remap every pixel through it (differing only slightly in rounding/minimum-CDF normalisation).

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `cv::equalizeHist(src, dst)` | `imageproc::contrast::equalize_histogram(&gray)` or `oximedia_cv::image::histogram_ext::equalize_histogram` |
| `cv::calcHist` | `imageproc::stats::histogram` or `oximedia_cv::image::Histogram::compute` |
