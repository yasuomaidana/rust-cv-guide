## Goal

Find the straight lines in a photograph, as OpenCV's `HoughLines` does. Two crates do it, `imageproc` and `oximedia-cv`, so the
page shows both and runs both on the same image. Both start from the same Canny edges.

## Theory

Every edge pixel `(x, y)` votes for the lines that could pass through it. A line is written in normal form,
`x · cos θ + y · sin θ = ρ`, where `θ` is the direction of its normal and `ρ` its distance from the origin. Each pixel votes
for one `ρ` per angle `θ`; many pixels on the same line vote for the same `(ρ, θ)`, so peaks in the vote table are the
lines. A threshold on the number of votes decides which peaks count, and a neighbouring peak of a real line is not a new line.

```rust
//! OpenCV tutorial `tutorial_hough_lines` in pure Rust: Canny edges, then the standard Hough line transform.
//! Run with `cargo run -p cvg-snippets --example hough_lines`.

use cvg_snippets::common::{Lines, gray_sample};
use image::GrayImage;
use imageproc::{
    edges::canny,
    hough::{LineDetectionOptions, detect_lines},
};

/// Neighbourhood radius (in accumulator buckets) the page starts with: only the strongest line in each 17 x 17 window is kept.
pub const SUPPRESSION: u32 = 8;

/// Lines that at least `votes` edge pixels lie on; only the strongest in each 17 x 17 bucket neighbourhood are kept.
pub fn lines(input: &GrayImage, votes: u32) -> Lines {
    lines_with(input, votes, SUPPRESSION)
}

/// [`lines`] keeping the strongest line in each `(2 * radius + 1)` square of buckets. Radius 1 is what
/// `cv::HoughLines` does, so it returns every local peak of the accumulator.
pub fn lines_with(input: &GrayImage, votes: u32, radius: u32) -> Lines {
    let options = LineDetectionOptions {
        vote_threshold: votes,
        suppression_radius: radius,
    };
    let found = detect_lines(&canny(input, 50.0, 150.0), options);
    found
        .iter()
        .map(|l| (l.r, (l.angle_in_degrees as f32).to_radians()))
        .collect()
}

/// Votes the page starts with.
pub const VOTES: u32 = 150;

/// How many lines the building photo gives.
pub fn report() -> String {
    format!(
        "lines = {}",
        lines(&gray_sample("building.jpg"), VOTES).len()
    )
}

pub fn main() {
    println!("{}", report());
}
```

```rust
//! OpenCV tutorial `tutorial_hough_lines` with `oximedia-cv` instead of `imageproc`.
//! Run with `cargo run -p cvg-snippets --example oxi_hough_lines`.

use cvg_snippets::common::{Lines, edge_points, gray_sample, suppress_lines};
use image::GrayImage;
use imageproc::edges::canny;
use oximedia_cv::hough_transform::{HoughAccumulator, HoughLineConfig};

/// Whether `(t_idx, r_idx)` has no strictly stronger neighbour in a `(2 * radius + 1)` square accumulator window (wrapping across `theta = PI`).
fn is_peak(acc: &HoughAccumulator, t_idx: usize, r_idx: usize, votes: u32, radius: isize) -> bool {
    let n_theta = (acc.num_theta - 1) as isize;
    for dt in -radius..=radius {
        let nt_raw = t_idx as isize + dt;
        let flip = nt_raw < 0 || nt_raw >= n_theta;
        let nt = nt_raw.rem_euclid(n_theta) as usize;
        let centre_r = if flip { acc.num_rho - 1 - r_idx } else { r_idx };
        let lo = centre_r.saturating_sub(radius as usize);
        let hi = (centre_r + radius as usize).min(acc.num_rho - 1);
        if acc.data[nt * acc.num_rho + lo..=nt * acc.num_rho + hi]
            .iter()
            .any(|&v| v > votes)
        {
            return false;
        }
    }
    true
}

/// Neighbourhood radius (in accumulator buckets) the page starts with: a 17 x 17 window.
pub const SUPPRESSION: u32 = 8;

/// Lines that at least `votes` Canny edge pixels lie on, using `HoughAccumulator` with 17x17 local-maximum suppression
/// and antipodal wrap-around (excluding the duplicate `theta = PI` row).
pub fn lines(input: &GrayImage, votes: u32) -> Lines {
    lines_with(input, votes, SUPPRESSION)
}

/// [`lines`] with a `(2 * radius + 1)` square suppression window; radius 1 is what `cv::HoughLines` does.
pub fn lines_with(input: &GrayImage, votes: u32, radius: u32) -> Lines {
    let config = HoughLineConfig {
        vote_threshold: votes,
        ..HoughLineConfig::default()
    };
    let mut acc = HoughAccumulator::new(input.width() as usize, input.height() as usize, &config);
    for (x, y) in edge_points(&canny(input, 50.0, 150.0)) {
        acc.vote(x, y);
    }
    let mut peaks = Vec::new();
    for t_idx in 0..acc.num_theta.saturating_sub(1) {
        for r_idx in 0..acc.num_rho {
            let count = acc.data[t_idx * acc.num_rho + r_idx];
            if count >= votes && is_peak(&acc, t_idx, r_idx, count, radius as isize) {
                let rho = (r_idx as f64 * acc.rho_resolution - acc.rho_offset) as f32;
                let theta = (t_idx as f64 * acc.theta_resolution) as f32;
                peaks.push((count, rho, theta));
            }
        }
    }
    peaks.sort_by_key(|a| std::cmp::Reverse(a.0));
    let sorted: Lines = peaks
        .into_iter()
        .map(|(_, rho, theta)| (rho, theta))
        .collect();
    suppress_lines(&sorted, radius as f32, (radius as f32).to_radians())
}

/// Votes the page starts with.
pub const VOTES: u32 = 150;

/// How many lines the building photo gives.
pub fn report() -> String {
    format!(
        "lines = {}",
        lines(&gray_sample("building.jpg"), VOTES).len()
    )
}

pub fn main() {
    println!("{}", report());
}
```

## Explanation

1. `canny(input, 50.0, 150.0)` gives the edges (the same step in both versions).
2. `imageproc::hough::detect_lines` takes the edge image and `LineDetectionOptions`: the votes needed and a suppression radius (`8`, a `17×17` block), keeping only strict local maxima. Its angles are whole degrees `0°..=179°`.
3. `oximedia_cv::hough_transform::HoughAccumulator` votes edge pixels into `(theta_idx, rho_idx)` bins. Calling the higher-level `hough_lines()` helper alone diverges from `imageproc` for three reasons: it includes a duplicate `θ = π` (`180°`) row without wrap-around, caps raw pre-suppression bins at `max_lines`, and returns un-suppressed vote shoulders.
4. To align the two outputs, the example votes into `HoughAccumulator`, excludes the duplicate `t_idx = 180` row, applies `17×17` local-maximum suppression (`is_peak`, wrapping across `θ = π`), and runs `suppress_lines` with antipodal equivalence `(ρ, θ) ≡ (-ρ, θ ± π)`.
5. Any remaining small count difference comes from sub-pixel `ρ` binning: `imageproc` truncates `r as i32` toward zero (creating a double-wide bin at `ρ = 0`), whereas `oximedia-cv` offsets by fractional `diag = sqrt(w² + h²)` and floors.
6. Tests verify both find a synthetic vertical edge at `(ρ = 50, θ = 0)` with no `θ = π` duplicate, and match across vote thresholds `100`, `150`, and `200`.

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `cv::Canny(src, edges, 50, 150)` | `imageproc::edges::canny` |
| `cv::HoughLines(edges, lines, 1, CV_PI/180, votes)` | `imageproc::hough::detect_lines`, or `oximedia_cv::hough_transform::HoughAccumulator` |
| `cv::line` over the polar lines | `common::draw_lines`, a few lines |
