## Goal

Apply the compound morphological operations of the OpenCV tutorial, opening, closing, top hat, black hat and the morphological
gradient, to a grey photograph. Two crates do it, `imageproc` and `oximedia-cv`, so the page shows both and runs both on the
same image.

## Theory

Erosion shrinks bright regions to the minimum of the window and dilation grows them to the maximum. Combining them gives:

- **opening** (erode, then dilate) removes bright specks smaller than the window and keeps the big shapes' size;
- **closing** (dilate, then erode) fills dark holes smaller than the window;
- **top hat** is the picture minus its opening: only the small bright things;
- **black hat** is the closing minus the picture: only the small dark things;
- **gradient** is dilation minus erosion: the outlines of the shapes.

```rust
//! OpenCV tutorial `tutorial_opening_closing_hats` in pure Rust: opening, closing, top hat, black hat and gradient.
//! Run with `cargo run -p cvg-snippets --example hats`.

use cvg_snippets::common::{Figure, Hats, describe, hat_figures};
use image::GrayImage;
use imageproc::morphology::{
    Mask, grayscale_close, grayscale_dilate, grayscale_erode, grayscale_open,
};

/// `a - b` per pixel, stopping at 0.
fn subtract(a: &GrayImage, b: &GrayImage) -> GrayImage {
    GrayImage::from_fn(a.width(), a.height(), |x, y| {
        image::Luma([a.get_pixel(x, y).0[0].saturating_sub(b.get_pixel(x, y).0[0])])
    })
}

/// Erosion then dilation: removes bright specks smaller than the window.
pub fn opening(grey: &GrayImage, radius: u8) -> GrayImage {
    grayscale_open(grey, &Mask::square(radius))
}

/// Dilation then erosion: fills dark holes smaller than the window.
pub fn closing(grey: &GrayImage, radius: u8) -> GrayImage {
    grayscale_close(grey, &Mask::square(radius))
}

/// The picture minus its opening: only the bright specks that the opening removed.
pub fn top_hat(grey: &GrayImage, radius: u8) -> GrayImage {
    subtract(grey, &opening(grey, radius))
}

/// The closing minus the picture: only the dark holes that the closing filled.
pub fn black_hat(grey: &GrayImage, radius: u8) -> GrayImage {
    subtract(&closing(grey, radius), grey)
}

/// Dilation minus erosion: the outlines of the shapes.
pub fn gradient(grey: &GrayImage, radius: u8) -> GrayImage {
    let window = Mask::square(radius);
    subtract(
        &grayscale_dilate(grey, &window),
        &grayscale_erode(grey, &window),
    )
}

/// The five operations as the shared figures code takes them.
pub const OPS: Hats = Hats {
    open: opening,
    close: closing,
    top_hat,
    black_hat,
    gradient,
};

/// The coin photo and the five operations on it with a 7x7 window.
pub fn figures() -> Vec<Figure> {
    hat_figures(&OPS)
}

/// Describes one pixel of each figure, on the edge of a coin.
pub fn report() -> String {
    describe(&figures(), 190, 150)
}

pub fn main() {
    println!("{}", report());
}
```

use cvg_snippets::{
    common::{Figure, Hats, describe, hat_figures},
    oxi,
};
use image::GrayImage;
use oximedia_cv::image::morph::{
    black_hat as black_hat_of, morphological_close, morphological_gradient, morphological_open,
    top_hat as top_hat_of,

/// Opening with a square window of `2 * radius + 1` pixels.
pub fn open(grey: &GrayImage, radius: u8) -> GrayImage {
    oxi::morph(grey, morphological_open, radius)
}

/// Closing with the same window.
pub fn close(grey: &GrayImage, radius: u8) -> GrayImage {
    oxi::morph(grey, morphological_close, radius)

    oxi::morph(grey, top_hat_of, radius)

## Explanation

1. `imageproc::morphology::grayscale_open` and `grayscale_close` take a `Mask`; `Mask::square(radius)` is the 5×5, 7×7, ... window of OpenCV's `getStructuringElement(MORPH_RECT, ..)`. (The plain `open`, `dilate` and `erode` of that module are for binary pictures, so a grey photo needs the `grayscale_` versions.)
2. The three derived operations are subtractions with `saturating_sub`, as OpenCV's `morphologyEx` does for `MORPH_TOPHAT`, `MORPH_BLACKHAT` and `MORPH_GRADIENT`.
3. `oximedia-cv` has all five as ready functions (`morphological_open`, `morphological_close`, `top_hat`, `black_hat`, `morphological_gradient`) that take grey bytes and a `StructuringElement::rectangle`.
4. Tests check that the two crates agree to under one grey level per pixel for every operation, that a lone bright pixel is removed by the opening and kept by the top hat (and the dark mirror image for closing and the black hat), and that opening never brightens and closing never darkens.

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `cv::morphologyEx(src, dst, MORPH_OPEN, kernel)` | `imageproc::morphology::grayscale_open`, or `oximedia_cv::image::morph::morphological_open` |
| `MORPH_CLOSE` | `grayscale_close`, or `morphological_close` |
| `MORPH_TOPHAT` / `MORPH_BLACKHAT` | `grey - open` / `close - grey`, or `top_hat` / `black_hat` |
| `MORPH_GRADIENT` | `grayscale_dilate - grayscale_erode`, or `morphological_gradient` |
| `cv::getStructuringElement(MORPH_RECT, Size(2r+1, 2r+1))` | `Mask::square(r)`, or `StructuringElement::rectangle(2r+1, 2r+1)` |

| Operation | Input | OpenCV | Pure Rust | oximedia / oxipix | oxi / Rust |

| Top-hat morphology (7x7, r=3) | 384x303 grey | 0.029 ms | 0.415 ms | 14.026 ms | 33.80x |

:::warning Performance difference

- **Top-hat morphology (7x7, r=3):** oximedia-cv top_hat is 33.8x slower than imageproc (507x slower than OpenCV) for a 7x7 square window due to non-separable 2D erode/dilate with per-pixel iter_active() coordinate division and bounds checks (cool-japan/oximedia#30).

:::
