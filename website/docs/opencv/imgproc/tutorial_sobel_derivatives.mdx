## Goal

Compute the horizontal and vertical Sobel derivatives of a photograph and combine them into a gradient magnitude, the
`cv::Sobel` recipe of the OpenCV tutorial. Both `imageproc` and `oximedia-cv` implement it side by side.

## Theory

The Sobel operator approximates the intensity derivative with a 3×3 kernel that differentiates in one direction and
smooths in the other. The x kernel responds to vertical edges and the y kernel to horizontal ones. The gradient
magnitude is `√(Gx² + Gy²)`, and the tutorial approximates it by blending the absolute values of both derivatives.

```rust
//! OpenCV tutorial `tutorial_sobel_derivatives` in pure Rust.
//! Run with `cargo run -p cvg-snippets --example sobel`.

use cvg_snippets::common::{Figure, SobelOps, describe, sobel_figures};
use image::{GrayImage, ImageBuffer, Luma};
use imageproc::gradients::{horizontal_sobel, sobel_gradients, vertical_sobel};

/// `cv::convertScaleAbs`: absolute value, saturated to 0..=255.
fn to_u8<T: Copy + Into<i32>>(derivative: &ImageBuffer<Luma<T>, Vec<T>>) -> GrayImage
where
    Luma<T>: image::Pixel<Subpixel = T>,
{
    GrayImage::from_fn(derivative.width(), derivative.height(), |x, y| {
        Luma([derivative.get_pixel(x, y)[0].into().unsigned_abs().min(255) as u8])
    })
}

/// `cv::Sobel` in x, as an 8-bit picture.
pub fn grad_x(input: &GrayImage) -> GrayImage {
    to_u8(&horizontal_sobel(input))
}

/// `cv::Sobel` in y, as an 8-bit picture.
pub fn grad_y(input: &GrayImage) -> GrayImage {
    to_u8(&vertical_sobel(input))
}

/// The gradient magnitude, as an 8-bit picture.
pub fn magnitude(input: &GrayImage) -> GrayImage {
    to_u8(&sobel_gradients(input))
}

/// The x, y, and magnitude functions bundled for `cvg-live`.
pub const OPS: SobelOps = (grad_x, grad_y, magnitude);

/// The photo's x and y Sobel derivatives and the gradient magnitude.
pub fn figures() -> Vec<Figure> {
    sobel_figures(OPS)
}

/// Describes one pixel of each figure.
pub fn report() -> String {
    describe(&figures(), 430, 300)
}

pub fn main() {
    println!("{}", report());
}
```

```rust
//! OpenCV tutorial `tutorial_sobel_derivatives` using `oximedia-cv::image::SobelEdge`.
//! Run with `cargo run -p cvg-snippets --example oxi_sobel`.

use cvg_snippets::{
    common::{Figure, SobelOps, describe, sobel_figures},
    oxi,
};
use image::GrayImage;
use oximedia_cv::image::SobelEdge;

fn to_u8(width: u32, height: u32, raw: Vec<i16>) -> GrayImage {
    let bytes: Vec<u8> = raw
        .into_iter()
        .map(|v| v.unsigned_abs().min(255) as u8)
        .collect();
    GrayImage::from_raw(width, height, bytes).expect("matching size")
}

fn deriv<E: std::fmt::Debug>(
    input: &GrayImage,
    axis: impl FnOnce(&SobelEdge, &[u8], u32, u32) -> Result<Vec<i16>, E>,
) -> GrayImage {
    let (w, h) = input.dimensions();
    let raw = axis(&SobelEdge::new(), input.as_raw(), w, h).expect("non-empty grey image");
    to_u8(w, h, raw)
}

/// `cv::Sobel` in x via `SobelEdge::gradient_x`, clamped to 8-bit.
pub fn grad_x(input: &GrayImage) -> GrayImage {
    deriv(input, |edge, raw, w, h| edge.gradient_x(raw, w, h))
}

/// `cv::Sobel` in y via `SobelEdge::gradient_y`, clamped to 8-bit.
pub fn grad_y(input: &GrayImage) -> GrayImage {
    deriv(input, |edge, raw, w, h| edge.gradient_y(raw, w, h))
}

/// Unnormalised gradient magnitude `sqrt(Gx² + Gy²)` clamped to 0..=255.
pub fn magnitude(input: &GrayImage) -> GrayImage {
    oxi::detect(input, &SobelEdge::new().with_normalize(false))
}

/// The x, y, and magnitude functions bundled for `cvg-live`.
pub const OPS: SobelOps = (grad_x, grad_y, magnitude);

/// The photo's x and y Sobel derivatives and the gradient magnitude.
pub fn figures() -> Vec<Figure> {
    sobel_figures(OPS)
}

/// Describes one pixel of each figure.
pub fn report() -> String {
    describe(&figures(), 430, 300)
}

pub fn main() {
    println!("{}", report());
}
```

## Explanation

1. `horizontal_sobel` / `vertical_sobel` (`imageproc`) and `SobelEdge::gradient_x` / `gradient_y` (`oximedia-cv`) return signed 16-bit images, because derivatives can be negative.
2. `sobel_gradients` (`imageproc`) and `SobelEdge::new().with_normalize(false).detect(..)` (`oximedia-cv`) compute the unnormalised magnitude directly.
3. `to_u8` takes the absolute value and saturates at 255, matching `cv::convertScaleAbs`.

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `cv::Sobel(src, dst, CV_16S, 1, 0)` | `imageproc::gradients::horizontal_sobel` or `oximedia_cv::image::SobelEdge::gradient_x` |
| `cv::Sobel(src, dst, CV_16S, 0, 1)` | `imageproc::gradients::vertical_sobel` or `oximedia_cv::image::SobelEdge::gradient_y` |
| `cv::convertScaleAbs` | `to_u8` above (absolute value, saturate to 255) |
| `cv::magnitude` | `imageproc::gradients::sobel_gradients` or `SobelEdge::new().with_normalize(false)` |

## Performance comparison

| Operation | Input | OpenCV | Pure Rust | oximedia / oxipix | oxi / Rust |
|---|---|---|---|---|---|
| Sobel X derivative | 640x480 grey | 0.141 ms | 3.847 ms | 0.784 ms | 0.20x |

:::warning Performance difference

- **Sobel X derivative:** Pure Rust imageproc Sobel X is ~4.9x slower than oximedia-cv (27.2x slower than OpenCV) because horizontal_sobel allocates an intermediate i16 buffer and remaps pixels separately, while oximedia-cv writes directly on the flat slice.

:::
