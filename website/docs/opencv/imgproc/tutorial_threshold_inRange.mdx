## Goal

Pick out the pixels of one colour with a range test in HSV, as OpenCV's `inRange` does. The page isolates the red pane of a
logo; the sliders let you pick any other colour. Both pure Rust (`image` only) and `oximedia-cv` (`rgb_to_hsv`) are shown side by side.

## Theory

In RGB a colour and its brightness are mixed up: a dark red and a bright red share no channel value. HSV separates them: **hue**
is the position on the colour wheel (0° red, 60° yellow, 120° green, 180° cyan, 240° blue, 300° magenta), **saturation** says how
far from grey, and **value** how bright. A colour range then is a hue interval plus a minimum saturation and value, which also keeps
out greys (no hue) and dark pixels (unreliable hue). Red sits at both ends of the hue wheel, so its range wraps through 0°.

## Code

The pure-Rust version converts RGB to HSV in degrees directly; the `oximedia-cv` version uses `oximedia_cv::image::convert::rgb_to_hsv`
(which packs hue as `0..=180`, matching OpenCV's 8-bit `H / 2`) followed by the range check. Native `in_range` masking in **oxipix** is tracked in `OXI-90`.

```rust
//! OpenCV tutorial `tutorial_threshold_inRange` in pure Rust: pick the pixels whose colour is in a range, in HSV.
//! Run with `cargo run -p cvg-snippets --example in_range`.

use cvg_snippets::common::{mask_keep, sample};
use image::{GrayImage, Luma, Rgb, RgbImage};

/// `cv::cvtColor(.., COLOR_RGB2HSV)` for one pixel: hue in degrees (0 to 360), saturation and value from 0 to 1.
pub fn rgb_to_hsv(Rgb([r, g, b]): Rgb<u8>) -> (f32, f32, f32) {
    let (r, g, b) = (
        f32::from(r) / 255.0,
        f32::from(g) / 255.0,
        f32::from(b) / 255.0,
    );
    let (high, low) = (r.max(g).max(b), r.min(g).min(b));
    let spread = high - low;
    let hue = if spread == 0.0 {
        0.0
    } else if high == r {
        60.0 * ((g - b) / spread).rem_euclid(6.0)
    } else if high == g {
        60.0 * ((b - r) / spread + 2.0)
    } else {
        60.0 * ((r - g) / spread + 4.0)
    };
    (hue, if high == 0.0 { 0.0 } else { spread / high }, high)
}

/// What the page asks for: hues from `low` to `high` degrees (a range with `low > high` wraps through red, as red does),
/// at least `saturation` saturated and at least `value` bright.
#[derive(Clone, Copy, Debug)]
pub struct Range {
    pub low: f32,
    pub high: f32,
    pub saturation: f32,
    pub value: f32,
}

/// `cv::inRange` on the HSV image: 255 where the pixel is in the range, 0 elsewhere.
pub fn in_range(input: &RgbImage, range: Range) -> GrayImage {
    GrayImage::from_fn(input.width(), input.height(), |x, y| {
        let (hue, saturation, value) = rgb_to_hsv(*input.get_pixel(x, y));
        let in_hue = if range.low <= range.high {
            hue >= range.low && hue <= range.high
        } else {
            hue >= range.low || hue <= range.high
        };
        Luma([
            if in_hue && saturation >= range.saturation && value >= range.value {
                255
            } else {
                0
            },
        ])
    })
}

/// `cv::bitwise_and(src, src, dst, mask)`: the picture where the mask is set, black elsewhere.
pub fn keep(input: &RgbImage, mask: &GrayImage) -> RgbImage {
    mask_keep(input, mask)
}

/// The red pane of the logo: hues from 345 through 0 to 15 degrees, clearly coloured and not dark.
pub const RED: Range = Range {
    low: 345.0,
    high: 15.0,
    saturation: 0.5,
    value: 0.4,
};

/// How many pixels the red range picks, and what a pixel of the red pane and one of the green pane become.
pub fn report() -> String {
    let photo = sample("WindowsLogo.jpg");
    let mask = in_range(&photo, RED);
    let kept = mask.pixels().filter(|p| p.0[0] > 0).count();
    let result = keep(&photo, &mask);
    format!(
        "in range = {kept} of {}\nred pane (150,80) = {:?}\ngreen pane (190,95) = {:?}",
        photo.width() * photo.height(),
        result.get_pixel(150, 80).0,
        result.get_pixel(190, 95).0
    )
}

pub fn main() {
    println!("{}", report());
}
```

```rust
//! OpenCV tutorial `tutorial_threshold_inRange` using `oximedia-cv::image::convert::rgb_to_hsv`.
//! Run with `cargo run -p cvg-snippets --example oxi_in_range`.

use cvg_snippets::common::{mask_keep, sample};
use image::{GrayImage, Luma, RgbImage};
use oximedia_cv::image::convert::rgb_to_hsv;

/// HSV thresholds (`low`/`high` hue in degrees, `saturation` and `value` in 0..=1).
#[derive(Clone, Copy, Debug)]
pub struct Range {
    pub low: f32,
    pub high: f32,
    pub saturation: f32,
    pub value: f32,
}

/// Converts the image with `oximedia_cv::image::convert::rgb_to_hsv` and builds the binary mask.
/// Note: `oximedia-cv` packs hue as `0..=180` (degrees / 2) and lacks a built-in `in_range` (tracked in `OXI-90`).
pub fn in_range(input: &RgbImage, range: Range) -> GrayImage {
    let (w, h) = input.dimensions();
    let hsv = rgb_to_hsv(input.as_raw(), w, h).expect("valid rgb image");
    let mut mask = vec![0u8; (w * h) as usize];
    for (dst, px) in mask.iter_mut().zip(hsv.as_chunks::<3>().0) {
        let hue = f32::from(px[0]) * 2.0;
        let sat = f32::from(px[1]) / 255.0;
        let val = f32::from(px[2]) / 255.0;
        let in_hue = if range.low <= range.high {
            hue >= range.low && hue <= range.high
        } else {
            hue >= range.low || hue <= range.high
        };
        if in_hue && sat >= range.saturation && val >= range.value {
            *dst = 255;
        }
    }
    GrayImage::from_raw(w, h, mask).expect("mask size")
}

/// Keeps only the pixels where `mask` is non-zero.
pub fn keep(input: &RgbImage, mask: &GrayImage) -> RgbImage {
    mask_keep(input, mask)
}

/// Selects pixels whose HSV colour lies in `(low..=high, saturation, value)`.
pub fn select(input: &RgbImage, low: f32, high: f32, saturation: f32, value: f32) -> RgbImage {
    let range = Range {
        low,
        high,
        saturation,
        value,
    };
    keep(input, &in_range(input, range))
}

/// The red pane of the logo: hues from 345 through 0 to 15 degrees.
pub const RED: Range = Range {
    low: 345.0,
    high: 15.0,
    saturation: 0.5,
    value: 0.4,
};

/// How many pixels the red range selects on `WindowsLogo.jpg`.
pub fn report() -> String {
    let photo = sample("WindowsLogo.jpg");
    let mask = in_range(&photo, RED);
    let kept = mask.pixels().filter(|p| p == &&Luma([255])).count();
    let result = keep(&photo, &mask);
    format!(
        "in range = {kept} of {}\nred pane (150,80) = {:?}\ngreen pane (190,95) = {:?}",
        photo.width() * photo.height(),
        result.get_pixel(150, 80).0,
        result.get_pixel(190, 95).0
    )
}

pub fn main() {
    println!("{}", report());
}
```

## Explanation

1. `rgb_to_hsv` converts RGB to `(H, S, V)` (degrees `0..360` in pure Rust; `0..=180` half-degrees in `oximedia-cv`, just like `CV_BGR2HSV`).
2. `in_range` tests each pixel's hue against the interval (with wrap-around when `low > high`), and its saturation and value against their minimums; the mask is 255 inside and 0 outside, like `cv::inRange` on the HSV image.
3. `keep` is `bitwise_and` with the mask: the colour pixels survive and the rest become black.
4. Tests verify pure-colour hues, wrap-around ranges, and parity between pure Rust and `oximedia-cv`.

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `cv::cvtColor(src, hsv, COLOR_BGR2HSV)` | `rgb_to_hsv` (pure Rust) or `oximedia_cv::image::convert::rgb_to_hsv` |
| `cv::inRange(hsv, lo, hi, mask)` | `in_range`, with the wrap-around for red (`oxipix` tracked in `OXI-90`) |
| `cv::bitwise_and(src, src, dst, mask)` | `keep` |
