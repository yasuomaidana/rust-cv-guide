## Goal

Rotate and scale a picture about its centre, as OpenCV's `warpAffine` does with the matrix of `getRotationMatrix2D`.
Both `imageproc` and `oximedia-cv` are shown side by side.

## Theory

An affine transform maps each point with a 2×3 matrix: it can move, rotate, scale and shear, and keeps straight lines
straight and parallel lines parallel. To rotate about the centre you first move the centre to the origin, rotate, scale, and
move it back; the product of those steps is one matrix. Every output pixel is then found by looking up where it came from in
the input (the inverse), and the in-between values are interpolated.

```rust
//! OpenCV tutorial `tutorial_warp_affine` in pure Rust: rotate and scale a picture about its centre with `warpAffine`.
//! Run with `cargo run -p cvg-snippets --example warp_affine`.

use cvg_snippets::common::{Figure, describe, rgb_figures, sample};
use image::{Rgb, RgbImage};
use imageproc::geometric_transformations::{Border, Interpolation, Projection, warp};

/// `cv::warpAffine` with the matrix of `cv::getRotationMatrix2D(centre, angle, scale)`: turns the picture by `degrees` clockwise
/// and scales it by `scale`, both about its centre; the output has the input's size and what falls outside is black.
pub fn rotate_scale(input: &RgbImage, degrees: f32, scale: f32) -> RgbImage {
    let (cx, cy) = (input.width() as f32 / 2.0, input.height() as f32 / 2.0);
    let about_centre = Projection::translate(-cx, -cy)
        .and_then(Projection::rotate(degrees.to_radians()))
        .and_then(Projection::scale(scale, scale))
        .and_then(Projection::translate(cx, cy));
    warp(
        input,
        about_centre,
        Interpolation::Bilinear,
        Border::Constant(Rgb([0, 0, 0])),
    )
}

/// The photo turned 30 degrees, shrunk to 0.6, and both.
pub fn figures() -> Vec<Figure> {
    let input = sample("astronaut.png");
    let results = [
        ("rotated", rotate_scale(&input, 30.0, 1.0)),
        ("scaled", rotate_scale(&input, 0.0, 0.6)),
        ("both", rotate_scale(&input, 30.0, 0.6)),
    ];
    rgb_figures(input.clone(), results)
}

/// Describes one pixel of each figure, off the centre (which the transform leaves in place).
pub fn report() -> String {
    describe(&figures(), 300, 200)
}

pub fn main() {
    println!("{}", report());
}
```

```rust
//! OpenCV tutorial `tutorial_warp_affine` using `oximedia-cv::transform::affine`.
//! Run with `cargo run -p cvg-snippets --example oxi_warp_affine`.

use cvg_snippets::common::{Figure, describe, rgb_figures, sample};
use image::RgbImage;
use oximedia_cv::transform::affine::{AffineTransform, warp_affine_image};

/// Rotates by `degrees` clockwise and scales by `scale` about the image centre using `warp_affine_image`.
pub fn rotate_scale(input: &RgbImage, degrees: f32, scale: f32) -> RgbImage {
    let (w, h) = (input.width() as usize, input.height() as usize);
    let (cx, cy) = (w as f64 / 2.0, h as f64 / 2.0);
    let forward = AffineTransform::translation(-cx, -cy)
        .rotate(f64::from(degrees).to_radians())
        .scale(f64::from(scale), f64::from(scale))
        .translate(cx, cy);
    let inv = forward.inverse().unwrap_or_else(AffineTransform::identity);
    let matrix = [[inv.a, inv.b, inv.tx], [inv.c, inv.d, inv.ty]];
    let out = warp_affine_image(input.as_raw(), w, h, 3, matrix, w, h).expect("valid warp");
    RgbImage::from_raw(input.width(), input.height(), out).expect("rgb buffer")
}

/// The photo turned 30 degrees, shrunk to 0.6, and both.
pub fn figures() -> Vec<Figure> {
    let input = sample("astronaut.png");
    let results = [
        ("rotated", rotate_scale(&input, 30.0, 1.0)),
        ("scaled", rotate_scale(&input, 0.0, 0.6)),
        ("both", rotate_scale(&input, 30.0, 0.6)),
    ];
    rgb_figures(input, results)
}

/// Describes one pixel of each figure.
pub fn report() -> String {
    describe(&figures(), 300, 200)
}

pub fn main() {
    println!("{}", report());
}
```

## Explanation

1. `Projection::translate(-cx, -cy).and_then(rotate).and_then(scale).and_then(translate(cx, cy))` (`imageproc`) and `AffineTransform::translation(-cx, -cy).rotate(..).scale(..).translate(cx, cy)` (`oximedia-cv`) build the same forward transform.
2. `imageproc::geometric_transformations::warp` inverts the projection internally, whereas `oximedia_cv::transform::affine::warp_affine_image` expects the inverse 2×3 matrix (`forward.inverse()`) directly.
3. Both sample bilinearly and fill out-of-bounds pixels with black; tests verify pixel agreement within a few grey levels.

## OpenCV to Rust

| OpenCV 5.1 | Rust |
|---|---|
| `cv::getRotationMatrix2D(center, angle, scale)` | `Projection` (`imageproc`) or `AffineTransform` (`oximedia-cv`) composed around `(cx, cy)` |
| `cv::warpAffine(src, dst, M, size)` | `imageproc::geometric_transformations::warp` or `oximedia_cv::transform::affine::warp_affine_image` |
| `cv::getAffineTransform(src, dst)` | `Projection::from_control_points` (four pairs) |
